# Session Notes — 2026-06-28

## Focus
Design Audit Agent: solve SPA empty-shell limitation and push score to 10/10.

## Problem Diagnosed
The audit agent was fetching the Lumynor site via HTTP and receiving an empty `<div id="root">` — no content to evaluate. All findings were either guesses or hallucinations. The LLM would invent issues for things it could not see, then when one was fixed it would invent a replacement.

---

## Solution: Playwright Headless Browser

Added full Playwright rendering to `design_audit.py`:

- `_fetch_page_playwright(url)` — launches headless Chromium, navigates, waits for `networkidle` + 2500ms hydration buffer, extracts full live DOM
- `_fetch_page_http(url)` — plain HTTP fallback (unchanged)
- `_fetch_page(url)` — tries Playwright first, falls back gracefully

**Railway build config** (`railway.toml`): added `buildCommand` to install Playwright Chromium at build time:
```
pip install -r requirements.txt && python -m playwright install chromium --with-deps
```

## Audit Agent — System Prompt Evolution (17 Rules)

Built up incrementally as LLM kept inventing new issues:

| Rule | What it prevents |
|---|---|
| 1–5 | Core grounding: use fetched data, never invent values |
| 6 | Only evidence-based failures cause score deductions |
| 7 | Every finding must cite a principle + specific fix |
| 8 | `primary_ctas` non-empty → C1-02 passes |
| 9 | `nav_links` is pre-deduplicated, don't double-count |
| 10 | `audience_statement` → C6-04 passes; hero H1 present → C1-01 passes |
| 11 | `active_nav_links` non-empty → C2-03 passes |
| 12 | PLACEMENT RULE: unverifiable items → `medium_issues` ONLY, never high/critical |
| 13 | C4-01 hover states → medium only (can't see CSS pseudo-states) |
| 14 | C4-07 loading indicators → medium only (invisible without form submit) |
| 15 | Nav ≤7 items → C2-01 passes (Miller's Law); only fail >7 |
| 16 | C1-02 = CTA visibility check, NOT uniqueness check; text link alongside btn-primary is fine |
| 17 | Visual density ("looks crowded") is a VISUAL claim, cannot make from DOM text → medium only |

---

## Context Builder Pre-Computed Verdicts

Rather than only trusting rules, the context block now announces verdicts inline next to the data so the LLM must explicitly override them to fail:

```
Navigation links (deduplicated — 5 items — PASSES C2-01 (within Miller's 7±2 rule)): [...]
★ PRIMARY CTA ELEMENTS [...]: ['Start Your Project', 'Contact Us']
  → C1-02 PASSES: a primary CTA is present and visible above the fold.
  → C6-01 STATUS: one btn-primary + subtle text link is NOT three competing goals.
★ HERO SECTION TEXT: [...]
  → C1-01 PASSES: hero section contains a clear H1 and value proposition.
★ ACTIVE NAV LINKS [...]: [...]
  → C2-03 PASSES
★ TARGET AUDIENCE STATEMENT: "For Startups, Founders & Growing Businesses"
  → C6-04 PASSES
```
